# Water Canal Distribution System using IoT

IoT-based water canal distribution and monitoring system for efficient water management and real-time monitoring.

## Project Overview

The Water Canal Distribution System using IoT is an automated irrigation water management solution designed to improve transparency, efficiency, and fairness in canal water distribution.

The system automates water allocation using Arduino Uno, flow sensors, and solenoid valves, reducing manual intervention and ensuring that farmers receive the required amount of water accurately.

## Problem Statement

Traditional canal water distribution systems rely on manual operations, which can lead to inefficient water allocation, water wastage, and lack of transparency. This project addresses these challenges through IoT-based monitoring and automated water flow control.

## Key Features

- Automated water distribution
- Real-time water flow monitoring
- Solenoid valve-based flow control
- Remote monitoring and management
- Reduced water wastage
- Improved transparency and accountability
- Admin and Farmer management modules

## Technologies Used

### Hardware
- Arduino Uno (ATmega328P)
- Water Flow Sensor
- Solenoid Valve

### Software
- Java
- MySQL
- JDBC
- RXTX Library (`gnu.io.*`)

## System Workflow

1. Farmer submits a water request.
2. Flow sensors monitor water flow.
3. Arduino processes sensor data.
4. Solenoid valves automatically regulate water distribution.
5. The required quantity of water is delivered.
6. Water usage is monitored and recorded.
